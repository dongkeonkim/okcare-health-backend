# fixture 회귀 검증

## 선행 조건

집계 조회 구현 여부를 [구현 단계와 리뷰 경계](../../../docs/설계/개발_계획.md#12-구현-단계와-리뷰-경계)의
경계 6에서 확인한다. 구현 전이면 검증을 수행하지 않고 어느 경계가 남았는지 보고한다.

## 기준 문서

- 회귀 입력: [`fixtures/health`](../../../fixtures/health)
- 검증 흐름: [회귀 및 E2E](../../../docs/설계/개발_계획.md#114-회귀-및-e2e)
- 입력 특성과 월간 회귀 기대값: [회귀 기준](../../../docs/명세/기능_명세.md#8-회귀-기준)
- 시간·숫자 정규화 기대 동작: [시간과 숫자 정규화](../../../docs/명세/기능_명세.md#52-시간과-숫자-정규화)
- 멱등 저장과 응답 카운트: [멱등 저장](../../../docs/명세/기능_명세.md#54-멱등-저장)
- 집계 응답 계약: [집계 조회](../../../docs/명세/기능_명세.md#6-집계-조회)
- 기대값 변경이 필요할 때의 문서 갱신: [변경 동기화](../../../docs/운영/문서_작성_가이드.md#4-변경-동기화)

## 보고 형식

`recordkey`별 월간 기대값과 실제값을 나란히 적고, 재전송 전후 레코드 수를 함께 보고한다. 건강 데이터 노출 범위는 [`AGENTS.md`](../../../AGENTS.md)를 따른다.
