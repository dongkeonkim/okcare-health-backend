# 문서 동기화 점검

점검과 보고만 하고 문서를 고치지 않는다. 수정은 보고 후 사용자가 승인한 범위에서 한다.

## 점검 대상

`README.md`, `AGENTS.md`, `CLAUDE.md`, `docs/` 아래 모든 문서, `.claude/rules/`와 `.claude/skills/`의 문서 참조.

## 기준 문서

- 문서별 독자와 책임: [문서별 책임](../../../docs/운영/문서_작성_가이드.md#2-문서별-책임)
- 작성 원칙: [작성 원칙](../../../docs/운영/문서_작성_가이드.md#3-작성-원칙)
- 변경 동기화 대상: [변경 동기화](../../../docs/운영/문서_작성_가이드.md#4-변경-동기화)
- 승인된 제품 범위: [`과제_원문.md`](../../../docs/요구사항/과제_원문.md), [`비즈니스_기획.md`](../../../docs/요구사항/비즈니스_기획.md)

## 보고 형식

항목별로 `파일:줄` 위치, 문제, 근거 문서 조항, 제안 조치를 적는다. 문제가 없으면 점검한 파일 수와 확인한 항목만 보고한다. 추측으로 문제를 만들지 않는다.
