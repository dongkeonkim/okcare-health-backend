# 백엔드 코드 리뷰

검토와 보고만 하고 코드를 고치지 않는다. 수정은 보고 후 사용자가 승인한 범위에서 한다.

## 리뷰 대상

```!
git status --short
```

```!
git diff --stat HEAD 2>/dev/null || git diff --stat
```
