# 리뷰 경계 보고

대상 경계: `$ARGUMENTS` (비어 있으면 현재 변경 내용으로 판단한다)

## 현재 작업 트리

```!
git status --short
```

```!
git log --oneline -5 2>/dev/null || echo "(아직 커밋 없음)"
```
