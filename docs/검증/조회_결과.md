# 건강활동 데이터 조회 결과

과제 원문의 제출물 3번(Daily/Monthly 레코드키 기준 조회 결과)에 해당합니다.

## 1. 조회 조건

제공된 네 입력 파일의 4,710건을 Docker Compose 실기동 환경에 저장한 뒤 실제 HTTP API로 조회했습니다.
집계 기준 시간대는 `Asia/Seoul`이며, 값은 응답 원문 그대로입니다. 월간 기대값의 단일 기준은
[`기능_명세.md`](../명세/기능_명세.md#8-회귀-기준)입니다.

- Daily: `GET /api/v1/health-data/daily`
- Monthly: `GET /api/v1/health-data/monthly`
- Daily 대표 조회 범위: `from=2024-11-15`, `to=2024-11-17`
- Monthly 전체 조회 범위: `from=2024-11`, `to=2024-12`
- `calories`가 `0.000000`인 두 `recordkey`는 입력에 칼로리가 없는 공급자 데이터
